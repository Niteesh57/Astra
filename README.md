# Astra

An interactive boxing and cognitive training website with a scroll-controlled red glove assembly, powered by Anime.js.

## Local preview

Run from this directory:

```sh
python -m http.server 4173 --directory dist
```

Open http://localhost:4173 in your browser. The site is buildless; all website assets are in `dist/`.

## Website

https://astra-training-universe.activebadger.chatgpt.site

The `.openai/hosting.json` file links this source to its existing Sites project. GitHub stores the source; publishing is managed through Sites.
